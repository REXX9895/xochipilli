
# 🎧 Xochipilli — Spotify Song Analysis

Xochipilli is an interactive music data analysis web application developed using Python, Streamlit, Pandas, and Plotly. It explores song popularity, genres, artists, and audio features through interactive charts, statistics, and data visualizations.

## ✨ Features

- 🎵 Explore song details and popularity.
- 📊 Visualize song popularity and genre distributions.
- 🎤 Analyze artists and their tracks.
- 🎚️ Explore audio features such as energy, danceability, and valence.
- 🔍 Filter songs by genre, popularity, and search keywords.
- 📥 Download filtered song data as a CSV file.

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- CSV datasets

## 🚀 Run Locally

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Install the required packages:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python -m streamlit run app.py
   ```

5. Open the local URL displayed in the terminal, usually `http://localhost:8501`.

## 📂 Dataset

The application uses a CSV dataset containing song information, including track names, artists, popularity, genres, and audio features. Upload a compatible CSV file through the app or place `dataset.csv` in the project folder if supported by the application.
